Quant Blazer is a set of tools for running rule-based strategies on futures and crypto: two downloaders that produce data you can trust, and Kraken Pilot, a desktop app that turns RealTest strategies into Kraken orders every day and waits for you to approve them.

Project 01 · Futures data

IQFeed Downloader

A single Rust binary that pulls IQFeed's back-adjusted continuous futures and writes one CSV per market per timeframe. Hourly bars come straight from IQFeed; daily bars are built from them by trade day, so they line up with the CME Globex session.

  • Full refresh by default. Back-adjusted history changes at every roll, so appending to an old file would mix adjustment bases.
  • Shrink guard. A new download replaces a file only if it keeps at least 90% of the existing rows. A truncated response never overwrites good history.
  • Atomic, repeatable writes. Files are written to a temp file, verified, then renamed. The same data gives a byte-identical file.
  • Built for unattended runs. Waits for IQFeed to log in, retries, and writes a per-symbol report with clear exit codes.

Micro futures covered: MES, MNQ, MYM, M2K, MCL, MGC

Project 02 · Crypto data

Kraken Downloader

Builds a local dataset of daily OHLCV candles for every USD-quoted crypto pair on Kraken. It uses public endpoints only, so no API keys are needed.

  • Full history from two sources. Kraken's REST endpoint returns only the latest 720 candles, so older history is imported from Kraken's bulk files and the API keeps it current.
  • Delisted pairs included. Pairs that no longer trade are kept, so backtests are not skewed by survivorship bias.
  • Exact values. Prices and volume are stored as the decimal strings Kraken sends, with no float rounding. The still-forming day is never written.
  • Verify command. Checks for gaps, bad timestamps and invalid bars, and compares stored candles against the live API.

Source on GitHub

# one-time history import, then daily updates
kraken-downloader import --path Kraken_OHLCVT.zip

Project 03 · Trading

Quant Blazer Kraken Pilot

One desktop app for trading a Kraken crypto book with RealTest strategies: daily data, orders runs, review and send, fills, daily backtests, history and a live-versus-backtest comparison.

  1. 1SyncFills, balances and net liquidation value from the Kraken account, at 00:30 UTC.
  2. 2DownloadDaily candles for every listed USD pair, waiting for the last closed day.
  3. 3OrdersRealTest orders runs for each Live strategy, sized from its share of the real account.
  4. 4ReviewEach order checked for caps, free cash, Kraken minimums and stops. The cycle never sends.
  5. 5SendYou confirm the exact orders. Exits go first, and a list is never sent twice.

How it works

  • Nothing is sent without you. Orders can be validated with Kraken first. On confirm, the app syncs again and sends only if the list is unchanged and nothing blocks it.
  • Live, Monitored, Archived. A strategy goes Live only with an allocation (all Live strategies add up to at most 100%) and a passing check run of its current version.
  • Live versus backtest. Each strategy's live results are matched trade by trade with its backtest, and the gap is split into slippage, fees, missed trades and extra trades.
  • History that cannot be rewritten. Every order, fill and trade change is appended to tables the database refuses to update or delete.
  • Notifications that only inform. Windows toasts, Telegram and email say when orders are ready or something failed. Nothing can be approved from a message.
  • Keys stay off disk. The Kraken API key lives in Windows Credential Manager, is checked before it is stored, and must have no withdrawal permission.
